# How to compile and execute using [Java Utils](https://www.github.com/PimousDev/JavaUtils)
First of all, you must use a Linux distribution! (That has `bash`).

> **Note:** `tmp/project` is were the project runs.

## Using only a terminal
1. Navigate to the project's root folder.
2. To compile, type `$ ./bin/compile.sh project`.
3. To execute, type `$ ./bin/execute.sh project`.

## Using VSCode
1. Use the shortcut `Ctrl + Shift + P` to open command panel.
2. Type `>Tasks: Run Task` to see project's tasks you can run.
3. Select or type `Execute java project sources.` to launch a task that will
compile and execute the project in VSCode's bash terminals.
